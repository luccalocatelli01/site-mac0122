Ordenação

Problemas

  • Dado um vetor de n elementos, colocá-los em ordem crescente.resolvido por: Ordenação por seleção direta

Exercícios extras de livros

Exercício 1

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 8.2.1 (adaptado).

Na ordenação por inserção direta, o laço interno anda para a esquerda enquanto v[i] > x. O que acontece se trocarmos a condição por v[i] >= x? O vetor continua sendo ordenado? O algoritmo continua estável?

Ver resolução

Continua ordenando: cada x ainda é colocado numa posição em que tudo à esquerda é menor ou igual a ele e tudo à direita é maior ou igual. Mas deixa de ser estável. Com >=, quando x encontra um elemento igual a ele, esse elemento também é empurrado para a direita, e x passa à frente dele. Exemplo: ordenando pela nota os pares (Ana, 7) e (Bia, 7), nessa ordem, a Bia termina antes da Ana, invertendo a ordem original dos empatados. Além disso, faz deslocamentos inúteis: elementos iguais são movidos sem necessidade. Por isso a versão com > é a correta.

Exercício 2

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 11.4.1 (adaptado).

Mostre que, se o vetor já estiver em ordem crescente, o quicksort que usa o último elemento como pivô faz cerca de n²/2 comparações. Por que isso acontece, e como evitar?

Ver resolução

Com o vetor ordenado, o último elemento é o maior. A separação compara o pivô com os outros n − 1 elementos, todos ficam à esquerda dele, e sobra um subvetor de tamanho n − 1 e outro vazio. Na chamada seguinte acontece o mesmo com n − 2, e assim por diante. O total é (n − 1) + (n − 2) + ... + 1 = n(n − 1)/2 comparações, O(n²): o quicksort cai no seu pior caso exatamente na entrada mais fácil. O programa abaixo conta as comparações e confirma: para n = 1000, são 499 500 no vetor ordenado contra cerca de 10 500 num vetor aleatório.

exercicio_ordenacao_2.c

/* Exercício: quantas comparações o quicksort faz num vetor já ordenado? */
#include <stdio.h>
#include <stdlib.h>

long comparacoes = 0;

/* separa v[inicio..fim] usando o último elemento como pivô */
int separa(int vetor[], int inicio, int fim) {
    int pivo = vetor[fim], posicao = inicio;
    for (int indice = inicio; indice < fim; indice++) {
        comparacoes++;
        if (vetor[indice] <= pivo) {
            int temporario = vetor[indice]; vetor[indice] = vetor[posicao]; vetor[posicao] = temporario;
            posicao++;
        }
    }
    int temporario = vetor[fim]; vetor[fim] = vetor[posicao]; vetor[posicao] = temporario;
    return posicao;
}

void quicksort(int vetor[], int inicio, int fim) {
    if (inicio >= fim) return;
    int posicao_do_pivo = separa(vetor, inicio, fim);
    quicksort(vetor, inicio, posicao_do_pivo - 1);
    quicksort(vetor, posicao_do_pivo + 1, fim);
}

int main(void) {
    int tamanhos[] = {10, 100, 1000};
    for (int teste = 0; teste < 3; teste++) {
        int quantidade = tamanhos[teste];
        int *ordenado = malloc(quantidade * sizeof(int));
        int *embaralhado = malloc(quantidade * sizeof(int));
        srand(1);
        for (int indice = 0; indice < quantidade; indice++) {
            ordenado[indice] = indice;
            embaralhado[indice] = rand() % 100000;
        }
        comparacoes = 0; quicksort(ordenado, 0, quantidade - 1);
        long no_ordenado = comparacoes;
        comparacoes = 0; quicksort(embaralhado, 0, quantidade - 1);
        printf("n=%4d  ordenado: %6ld comparações (n(n-1)/2 = %6d)  aleatório: %6ld\n",
               quantidade, no_ordenado, quantidade * (quantidade - 1) / 2, comparacoes);
        free(ordenado); free(embaralhado);
    }
    return 0;
}

Para evitar, escolha o pivô de outro jeito: sorteando uma posição (quicksort aleatorizado, exercício 11.5.3 do mesmo livro) ou usando a mediana entre o primeiro, o do meio e o último.

Árvore

Exercícios extras de livros

Exercício 1

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 14.2.2 (adaptado).

Escreva uma função recursiva que conta os nós de uma árvore binária.

Ver resolução

A definição recursiva da árvore dá a função quase pronta: uma árvore vazia tem 0 nós; senão, tem a raiz mais os nós da subárvore esquerda mais os da direita. Cada nó é visitado uma vez, então o consumo de tempo é O(n). O mesmo esquema calcula a altura (1 + o maior entre as alturas das subárvores) e a quantidade de folhas, que caíram na Q5 da P1. O programa abaixo resolve este exercício e o próximo.

exercicio_arvore_1.c

/* Exercício: contar os nós e imprimir as folhas (em ordem e-r-d) de uma árvore binária. */
#include <stdio.h>
#include <stdlib.h>

typedef struct NoDaArvore {
    int conteudo;
    struct NoDaArvore *esquerda, *direita;
} NoDaArvore;

/* nós da árvore = 0 se vazia; senão 1 (a raiz) + nós da esquerda + nós da direita */
int contar_nos(NoDaArvore *raiz) {
    if (raiz == NULL) return 0;
    return 1 + contar_nos(raiz->esquerda) + contar_nos(raiz->direita);
}

/* e-r-d: esquerda, raiz, direita; só imprime quem não tem filhos */
void imprimir_folhas(NoDaArvore *raiz) {
    if (raiz == NULL) return;
    imprimir_folhas(raiz->esquerda);
    if (raiz->esquerda == NULL && raiz->direita == NULL) printf("%d ", raiz->conteudo);
    imprimir_folhas(raiz->direita);
}

NoDaArvore *novo_no(int conteudo, NoDaArvore *esquerda, NoDaArvore *direita) {
    NoDaArvore *no = malloc(sizeof(NoDaArvore));
    no->conteudo = conteudo;
    no->esquerda = esquerda;
    no->direita = direita;
    return no;
}

void liberar(NoDaArvore *raiz) {
    if (raiz == NULL) return;
    liberar(raiz->esquerda);
    liberar(raiz->direita);
    free(raiz);
}

int main(void) {
    /*        1
            /   \
           2     3
          / \     \
         4   5     6      */
    NoDaArvore *raiz = novo_no(1, novo_no(2, novo_no(4, NULL, NULL), novo_no(5, NULL, NULL)),
                                  novo_no(3, NULL, novo_no(6, NULL, NULL)));
    printf("nós: %d\n", contar_nos(raiz));   /* 6 */
    printf("folhas: ");
    imprimir_folhas(raiz);                    /* 4 5 6 */
    printf("\n");
    liberar(raiz);
    return 0;
}

Busca

Exercícios extras de livros

Exercício 1

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 7.3.2 (adaptado).

Faça o rastreamento da busca binária no vetor v = {10, 20, 30, 40, 50, 60, 70} (n = 7), mostrando os valores de e (esquerda), m (meio) e d (direita) a cada iteração, primeiro para x = 55 e depois para x = 20. Quantas iterações cada busca faz?

Ver resolução

Para x = 55 (não está no vetor):

e=0 m=3 d=6  v[3]=40 < 55  -> e = 4
e=4 m=5 d=6  v[5]=60 > 55  -> d = 4
e=4 m=4 d=4  v[4]=50 < 55  -> e = 5
e=5 > d=4: para, x não está no vetor

Para x = 20 (está na posição 1):

e=0 m=3 d=6  v[3]=40 > 20  -> d = 2
e=0 m=1 d=2  v[1]=20 = 20  -> achou na posição 1

A busca sem sucesso fez 3 iterações e a com sucesso, 2. Com n = 7, nenhuma busca passa de 3 iterações, porque cada uma corta o intervalo pela metade: 7, 3, 1. Em geral são no máximo cerca de log₂ n + 1 iterações, O(log n). O programa abaixo imprime esse rastreamento.

exercicio_busca_1.c

/* Exercício: rastrear a busca binária, mostrando e, m e d a cada passo. */
#include <stdio.h>

int busca_binaria(int vetor[], int quantidade, int procurado) {
    int esquerda = 0, direita = quantidade - 1;
    while (esquerda <= direita) {
        int meio = esquerda + (direita - esquerda) / 2;   /* sem overflow */
        printf("e=%d m=%d d=%d v[m]=%d\n", esquerda, meio, direita, vetor[meio]);
        if (vetor[meio] == procurado) return meio;
        if (vetor[meio] < procurado) esquerda = meio + 1;
        else direita = meio - 1;
    }
    return -1;
}

int main(void) {
    int vetor[] = {10, 20, 30, 40, 50, 60, 70};
    printf("-> resultado %d\n\n", busca_binaria(vetor, 7, 55));
    printf("-> resultado %d\n", busca_binaria(vetor, 7, 20));
    return 0;
}

Exercício 2

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 7.5.3 (adaptado).

Na busca binária, o meio costuma ser calculado como m = (e + d) / 2. Explique por que essa conta pode dar errado para vetores muito grandes e como evitar o problema.

Ver resolução

Em C, int tem um valor máximo (2 147 483 647 com 32 bits). Se o vetor for enorme, e + d pode passar desse máximo antes da divisão por 2: é um overflow, e o resultado vira um número negativo ou sem sentido, mesmo que e e d sozinhos sejam válidos. A solução é calcular o meio como m = e + (d − e) / 2. Matematicamente é o mesmo valor, mas d − e é sempre pequeno (é o tamanho do intervalo), então nenhuma conta passa do máximo. O programa do exercício anterior já usa essa forma.

Exercícios extras de livros

Exercício 1

Fonte: FEOFILOFF, P. Análise de Algoritmos: repositório de exercícios. São Paulo: IME-USP, 2018. Exercício 4.11 (adaptado).

Quantas vezes o corpo do laço abaixo é executado quando n = 100? E para um n qualquer? Qual é a ordem de grandeza do consumo de tempo?

while (n > 1)
    n = n / 2;
Ver resolução

Para n = 100, o valor de n passa por 100, 50, 25, 12, 6, 3 e 1: o corpo roda 6 vezes. Em geral, cada volta divide n por 2, então depois de k voltas sobra mais ou menos n / 2^k. O laço para quando isso chega a 1, ou seja, quando 2^k passa de n. O número de voltas é o piso de log₂ n (para n = 100, log₂ 100 ≈ 6,6, piso 6). É a regra que caiu na P1: quando o contador é multiplicado ou dividido a cada passo, o laço é O(log n).

Exercício 2

Fonte: FEOFILOFF, P. Análise de Algoritmos: repositório de exercícios. São Paulo: IME-USP, 2018. Exercícios 4.1 e 4.2 (adaptado).

Na ordenação por inserção direta, conte quantas comparações v[i] > x são feitas no melhor caso e no pior caso para um vetor de n elementos. Que vetores produzem cada caso? Escreva o resultado em notação O.

Ver resolução

O laço externo pega v[j] (j = 1, ..., n − 1) e o laço interno anda para a esquerda enquanto v[i] > x. Melhor caso: vetor já em ordem crescente. Para cada j, a primeira comparação já falha, então é 1 comparação por j: n − 1 no total, O(n). Pior caso: vetor em ordem decrescente. Para cada j, x é menor que todos os anteriores e o laço interno percorre as j posições: 1 + 2 + ... + (n − 1) = n(n − 1)/2 comparações, O(n²). Por isso a inserção direta é boa para vetores quase ordenados, mesmo sendo quadrática no pior caso.

Espalhamento

Exercícios extras de livros

Exercício 1

Fonte: CORMEN, T. H.; LEISERSON, C. E.; RIVEST, R. L.; STEIN, C. Algoritmos: teoria e prática. 3. ed. Rio de Janeiro: Elsevier, 2012. Exercício 11.2-2 (adaptado).

Insira as chaves 5, 28, 19, 15, 20, 33, 12, 17, 10, nessa ordem, numa tabela de espalhamento com 9 posições, função h(k) = k mod 9 e colisões tratadas por encadeamento externo (cada nova chave entra no começo da lista da sua posição). Desenhe a tabela final.

Ver resolução

Calculando h(k) = k mod 9: 5→5, 28→1, 19→1, 15→6, 20→2, 33→6, 12→3, 17→8, 10→1.

0: (vazia)
1: 10 -> 19 -> 28
2: 20
3: 12
4: (vazia)
5: 5
6: 33 -> 15
7: (vazia)
8: 17

As colisões aconteceram nas posições 1 (28, 19 e 10) e 6 (15 e 33). Como cada chave nova entra no começo da lista, a última inserida fica na frente. Se a inserção fosse no fim da lista, as listas seriam 28 -> 19 -> 10 e 15 -> 33; as duas formas estão certas, mas inserir no começo custa O(1).

Exercício 2

Fonte: CORMEN, T. H.; LEISERSON, C. E.; RIVEST, R. L.; STEIN, C. Algoritmos: teoria e prática. 3. ed. Rio de Janeiro: Elsevier, 2012. Seção 11.2, análise do encadeamento (adaptado).

Na tabela do exercício anterior (9 posições, h(k) = k mod 9), escolha 5 chaves que façam a busca ficar o mais lenta possível. Com n chaves, quanto custa uma busca sem sucesso no pior caso? E no caso médio, supondo que a função espalha bem?

Ver resolução

Basta que todas as chaves tenham o mesmo resto na divisão por 9, por exemplo 1, 10, 19, 28 e 37: todas vão para a lista da posição 1 e a tabela vira uma lista ligada comum. Pior caso: as n chaves na mesma lista, e uma busca sem sucesso percorre todas, O(n). Caso médio: se a função espalha as chaves de maneira uniforme pelas m posições, cada lista tem em média n/m chaves (o fator de carga α). Uma busca sem sucesso calcula h(k) e percorre uma lista inteira, custo O(1 + α). Se m cresce junto com n, α fica constante e a busca é O(1), que é o resultado da P1: O(1) no caso médio e O(n) no pior. É o mesmo problema da função vista em aula que soma os códigos ASCII: anagramas como "abc" e "cba" sempre colidem, então ela espalha mal conjuntos de palavras parecidas.

Fila

Exercícios extras de livros

Exercício 1

Fonte: CORMEN, T. H.; LEISERSON, C. E.; RIVEST, R. L.; STEIN, C. Algoritmos: teoria e prática. 3. ed. Rio de Janeiro: Elsevier, 2012. Exercício 10.1-6 (adaptado).

Mostre como implementar uma fila usando duas pilhas e analise o consumo de tempo das operações de inserir e remover.

Ver resolução

Use uma pilha entrada, que recebe quem chega, e uma pilha saida, de onde sai o próximo da fila. Inserir: empilha em entrada. Remover: se saida estiver vazia, desempilha tudo de entrada e empilha em saida (isso inverte a ordem e deixa o mais antigo no topo); depois desempilha de saida. Inserir custa O(1). Remover custa O(n) no pior caso, quando precisa passar tudo de uma pilha para a outra. Mas cada elemento passa de entrada para saida no máximo uma vez, então numa sequência de operações o custo médio por operação é O(1) (custo amortizado).

exercicio_fila_1.c

/* Exercício: fila feita com duas pilhas. */
#include <stdio.h>

#define TAMANHO 100

typedef struct {
    int itens[TAMANHO];
    int topo;                 /* -1 = vazia */
} Pilha;

void empilhar(Pilha *pilha, int valor) { pilha->itens[++pilha->topo] = valor; }
int desempilhar(Pilha *pilha) { return pilha->itens[pilha->topo--]; }
int pilha_vazia(const Pilha *pilha) { return pilha->topo == -1; }

/* entrada recebe quem chega; saida entrega quem sai.
   Ao passar tudo de entrada para saida, a ordem se inverte e o mais antigo
   fica no topo de saida. */
typedef struct {
    Pilha entrada;
    Pilha saida;
} Fila;

void inserir(Fila *fila, int valor) {
    empilhar(&fila->entrada, valor);
}

int remover(Fila *fila) {
    if (pilha_vazia(&fila->saida)) {
        while (!pilha_vazia(&fila->entrada)) {
            empilhar(&fila->saida, desempilhar(&fila->entrada));
        }
    }
    return desempilhar(&fila->saida);   /* supõe fila não vazia */
}

int main(void) {
    Fila fila = { .entrada = { .topo = -1 }, .saida = { .topo = -1 } };
    inserir(&fila, 1); inserir(&fila, 2); inserir(&fila, 3);
    printf("%d ", remover(&fila));      /* 1 */
    inserir(&fila, 4);
    printf("%d ", remover(&fila));      /* 2 */
    printf("%d ", remover(&fila));      /* 3 */
    printf("%d\n", remover(&fila));     /* 4 */
    return 0;
}

Exercício 2

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 5.3.1 (adaptado).

Implemente uma fila circular num vetor de capacidade fixa, com as funções tamanho, inserir (que avisa quando a fila está cheia) e remover.

Ver resolução

Guarde a posição do primeiro elemento (inicio) e a quantidade de elementos. O fim da fila é (inicio + quantidade) % CAPACIDADE: o resto da divisão faz a fila dar a volta no vetor, reaproveitando as posições liberadas no começo. A fila está cheia quando quantidade == CAPACIDADE, e vazia quando quantidade == 0. Guardar a quantidade evita a ambiguidade da versão com dois índices, em que inicio == fim pode significar cheia ou vazia. Todas as operações são O(1).

exercicio_fila_2.c

/* Exercício: fila circular num vetor, com tamanho e aviso de fila cheia. */
#include <stdio.h>

#define CAPACIDADE 5

typedef struct {
    int itens[CAPACIDADE];
    int inicio;        /* posição do primeiro da fila */
    int quantidade;    /* quantos elementos há na fila */
} Fila;

int tamanho(const Fila *fila) { return fila->quantidade; }

/* Devolve 0 se a fila estava cheia. */
int inserir(Fila *fila, int valor) {
    if (fila->quantidade == CAPACIDADE) return 0;
    int fim = (fila->inicio + fila->quantidade) % CAPACIDADE;   /* dá a volta no vetor */
    fila->itens[fim] = valor;
    fila->quantidade++;
    return 1;
}

/* Supõe fila não vazia. */
int remover(Fila *fila) {
    int valor = fila->itens[fila->inicio];
    fila->inicio = (fila->inicio + 1) % CAPACIDADE;
    fila->quantidade--;
    return valor;
}

int main(void) {
    Fila fila = { .inicio = 0, .quantidade = 0 };
    for (int valor = 1; valor <= 5; valor++) inserir(&fila, valor);
    printf("inserir 6 na fila cheia: %s\n", inserir(&fila, 6) ? "ok" : "fila cheia");
    int primeiro = remover(&fila);
    int segundo = remover(&fila);
    printf("%d %d\n", primeiro, segundo);                /* 1 2 */
    inserir(&fila, 6); inserir(&fila, 7);                 /* usam as posições 0 e 1 de novo */
    printf("tamanho: %d\n", tamanho(&fila));              /* 5 */
    while (tamanho(&fila) > 0) printf("%d ", remover(&fila));   /* 3 4 5 6 7 */
    printf("\n");
    return 0;
}

Indução

Exercícios extras de livros

Exercício 1

Fonte: FEOFILOFF, P. Análise de Algoritmos: repositório de exercícios. São Paulo: IME-USP, 2018. Exercício 1.23 (adaptado).

Prove por indução que, para todo n ≥ 0, 1 + 2 + 2² + ... + 2ⁿ = 2ⁿ⁺¹ − 1.

Ver resolução

Base (n = 0): o lado esquerdo é só 1 e o direito é 2¹ − 1 = 1. Vale. Hipótese de indução: suponha que a igualdade vale para n − 1, ou seja, 1 + 2 + ... + 2ⁿ⁻¹ = 2ⁿ − 1. Passo: 1 + 2 + ... + 2ⁿ⁻¹ + 2ⁿ = (2ⁿ − 1) + 2ⁿ = 2 · 2ⁿ − 1 = 2ⁿ⁺¹ − 1, usando a hipótese na primeira igualdade. Logo vale para n. Essa soma aparece nas Torres de Hanói: o número de movimentos para n discos é 2ⁿ − 1, e uma árvore binária completa de altura h tem 2ʰ⁺¹ − 1 nós.

Exercício 2

Fonte: FEOFILOFF, P. Análise de Algoritmos: repositório de exercícios. São Paulo: IME-USP, 2018. Exercício 8.2 (adaptado).

Uma árvore binária é cheia quando cada nó tem 0 ou 2 filhos. Prove por indução que uma árvore binária cheia com f folhas tem exatamente f − 1 nós internos (nós com filhos).

Ver resolução

Indução no número de nós. Base: a árvore com um só nó. Ele é folha, então f = 1, e há 0 = f − 1 nós internos. Vale. Hipótese: a afirmação vale para toda árvore binária cheia com menos nós que a árvore T. Passo: se T tem mais de um nó, a raiz é interna e tem duas subárvores, E e D, ambas cheias e menores que T. Se E tem f₁ folhas e D tem f₂, pela hipótese elas têm f₁ − 1 e f₂ − 1 nós internos. As folhas de T são as de E e de D: f = f₁ + f₂. Os nós internos de T são os de E, os de D e a raiz: (f₁ − 1) + (f₂ − 1) + 1 = f₁ + f₂ − 1 = f − 1. Vale para T. Aplicação: a árvore de expressão da P1 é cheia (cada operador tem dois operandos), então uma expressão com f números tem f − 1 operadores.

Lista ligada

Exercícios extras de livros

Exercício 1

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 4.7.11 (adaptado).

Escreva uma função que inverte a ordem das células de uma lista ligada sem criar células novas: só os ponteiros podem mudar.

Ver resolução

A ideia é andar pela lista virando a seta de cada célula para trás. São necessários três ponteiros: anterior (a parte já invertida), atual (a célula sendo virada) e seguinte (guardado antes de virar a seta, senão o resto da lista se perde). Invariante: no começo de cada volta, anterior aponta para a parte já invertida e atual para o resto, ainda na ordem original. Quando atual fica NULL, anterior é o novo primeiro nó. O consumo de tempo é O(n) e a memória extra é constante.

exercicio_lista_ligada_1.c

/* Exercício: inverter uma lista ligada sem criar células novas. */
#include <stdio.h>
#include <stdlib.h>

typedef struct No {
    int conteudo;
    struct No *proximo;
} No;

/* Inverte a lista e devolve o endereço do novo primeiro nó.
   Cada nó tem o ponteiro "proximo" virado para trás, um de cada vez. */
No *inverter(No *lista) {
    No *anterior = NULL;
    No *atual = lista;
    while (atual != NULL) {
        No *seguinte = atual->proximo;   /* guarda antes de perder */
        atual->proximo = anterior;       /* vira a seta */
        anterior = atual;                /* anda os dois um passo */
        atual = seguinte;
    }
    return anterior;                     /* o antigo último nó */
}

No *inserir_no_comeco(No *lista, int valor) {
    No *novo = malloc(sizeof(No));
    novo->conteudo = valor;
    novo->proximo = lista;
    return novo;
}

void imprimir(No *lista) {
    for (No *atual = lista; atual != NULL; atual = atual->proximo) printf("%d ", atual->conteudo);
    printf("\n");
}

int main(void) {
    No *lista = NULL;
    for (int valor = 5; valor >= 1; valor--) lista = inserir_no_comeco(lista, valor);
    imprimir(lista);            /* 1 2 3 4 5 */
    lista = inverter(lista);
    imprimir(lista);            /* 5 4 3 2 1 */
    while (lista != NULL) { No *proximo = lista->proximo; free(lista); lista = proximo; }
    return 0;
}

Exercício 2

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 4.6.3 (adaptado; aqui com No **, como na P1).

Escreva uma função que remove de uma lista ligada todas as células cujo conteúdo é x. A primeira célula também pode ter que ser removida.

Ver resolução

Usando um ponteiro para ponteiro (No **), o caso da primeira célula deixa de ser especial: ponteiro_atual aponta sempre para o campo que guarda o endereço da célula examinada (no começo, a própria variável lista; depois, o campo proximo da célula anterior). Se a célula tem x, esse campo passa a apontar para a seguinte, a célula é liberada e ponteiro_atual não anda, porque a nova célula naquela posição ainda não foi examinada. Se não tem x, ponteiro_atual avança para &(célula)->proximo. Cuidado comum: avançar depois de remover, o que pula células e falha em casos como 7 -> 7 -> 3.

exercicio_lista_ligada_2.c

/* Exercício: remover de uma lista ligada todas as células com conteúdo x. */
#include <stdio.h>
#include <stdlib.h>

typedef struct No {
    int conteudo;
    struct No *proximo;
} No;

/* ponteiro_para_lista aponta para o ponteiro que guarda o primeiro nó
   (o mesmo truque do No **ptLista da P1): assim o primeiro nó não é um
   caso especial. */
void remover_todos(No **ponteiro_para_lista, int valor) {
    No **ponteiro_atual = ponteiro_para_lista;
    while (*ponteiro_atual != NULL) {
        if ((*ponteiro_atual)->conteudo == valor) {
            No *removido = *ponteiro_atual;
            *ponteiro_atual = removido->proximo;   /* quem apontava para ele pula ele */
            free(removido);
            /* não anda: o novo *ponteiro_atual ainda não foi examinado */
        } else {
            ponteiro_atual = &(*ponteiro_atual)->proximo;
        }
    }
}

No *inserir_no_comeco(No *lista, int valor) {
    No *novo = malloc(sizeof(No));
    novo->conteudo = valor;
    novo->proximo = lista;
    return novo;
}

void imprimir(No *lista) {
    for (No *atual = lista; atual != NULL; atual = atual->proximo) printf("%d ", atual->conteudo);
    printf("\n");
}

int main(void) {
    int valores[] = {7, 7, 3, 7, 5, 7};
    No *lista = NULL;
    for (int indice = 5; indice >= 0; indice--) lista = inserir_no_comeco(lista, valores[indice]);
    imprimir(lista);              /* 7 7 3 7 5 7 */
    remover_todos(&lista, 7);
    imprimir(lista);              /* 3 5 */
    while (lista != NULL) { No *proximo = lista->proximo; free(lista); lista = proximo; }
    return 0;
}

Exercícios extras de livros

Exercício 1

Fonte: CORMEN, T. H.; LEISERSON, C. E.; RIVEST, R. L.; STEIN, C. Algoritmos: teoria e prática. 3. ed. Rio de Janeiro: Elsevier, 2012. Exercício 10.1-1 (adaptado).

Uma pilha está guardada num vetor S[0..5] e começa vazia (topo = −1). Mostre o conteúdo do vetor e o valor de topo depois de cada operação: empilha(4), empilha(1), empilha(3), desempilha, empilha(8), desempilha.

Ver resolução 
operação       S[0] S[1] S[2]   topo   devolve
empilha(4)      4                  0
empilha(1)      4    1             1
empilha(3)      4    1    3        2
desempilha      4    1   (3)       1      3
empilha(8)      4    1    8        2
desempilha      4    1   (8)       1      8

No fim, a pilha contém 4 e 1, com o 1 no topo. Repare que desempilhar só diminui topo: o valor continua no vetor (entre parênteses), mas não faz mais parte da pilha e é sobrescrito no próximo empilha. É o mesmo esquema da P1: topo = −1 vazia, ++topo empilha, topo−− desempilha.

Exercício 2

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 6.1.3 (adaptado).

Os números 1, 2, 3, 4 chegam nessa ordem. A cada passo podemos empilhar o próximo número que chega ou desempilhar o topo e escrevê-lo na saída. Quais das 24 ordens de 1, 2, 3, 4 podem aparecer na saída? Dê uma regra para reconhecer as impossíveis.

Ver resolução

14 das 24 ordens são possíveis. As 10 impossíveis são:

1 4 2 3    2 4 1 3    3 1 2 4    3 1 4 2    3 4 1 2
4 1 2 3    4 1 3 2    4 2 1 3    4 2 3 1    4 3 1 2

Regra: uma ordem é impossível quando tem um número grande, depois um pequeno, depois um médio (o padrão "3 1 2"). Por exemplo, em 3 1 2 4: para escrever o 3, o 1 e o 2 tiveram que ser empilhados antes dele, com o 2 por cima do 1. Então o 2 sai antes do 1, e a ordem 3 1 2 não pode acontecer. O programa abaixo testa as 24 ordens simulando a pilha.

exercicio_pilha_2.c

/* Exercício: quais permutações de 1 2 3 4 saem de uma pilha?
   Os números entram em ordem (1, 2, 3, 4); a cada passo podemos empilhar o
   próximo da entrada ou desempilhar o topo para a saída. */
#include <stdio.h>

#define QUANTIDADE 4

/* Simula: devolve 1 se a pilha consegue produzir a sequência desejada. */
int pilha_produz(const int desejada[]) {
    int pilha[QUANTIDADE], topo = -1;
    int proximo_da_entrada = 1;
    for (int posicao = 0; posicao < QUANTIDADE; posicao++) {
        /* empilha até o número desejado aparecer no topo */
        while (proximo_da_entrada <= QUANTIDADE && (topo == -1 || pilha[topo] != desejada[posicao])) {
            pilha[++topo] = proximo_da_entrada++;
        }
        if (topo == -1 || pilha[topo] != desejada[posicao]) return 0;   /* ficou embaixo de outro */
        topo--;
    }
    return 1;
}

/* Gera as 24 permutações em ordem crescente e testa cada uma. */
void testar_permutacoes(int permutacao[], int usados[], int posicao, int *possiveis) {
    if (posicao == QUANTIDADE) {
        int produz = pilha_produz(permutacao);
        *possiveis += produz;
        printf("%d %d %d %d  %s\n", permutacao[0], permutacao[1], permutacao[2], permutacao[3],
               produz ? "sim" : "NÃO");
        return;
    }
    for (int valor = 1; valor <= QUANTIDADE; valor++) {
        if (usados[valor]) continue;
        usados[valor] = 1;
        permutacao[posicao] = valor;
        testar_permutacoes(permutacao, usados, posicao + 1, possiveis);
        usados[valor] = 0;
    }
}

int main(void) {
    int permutacao[QUANTIDADE], usados[QUANTIDADE + 1] = {0}, possiveis = 0;
    testar_permutacoes(permutacao, usados, 0, &possiveis);
    printf("possíveis: %d de 24\n", possiveis);
    return 0;
}

Exercícios extras de livros

Exercício 1

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 2.3.3 (adaptado).

Escreva uma função recursiva que calcula a soma dos elementos positivos de um vetor v[0..n−1]. Quanto deve valer a soma quando n = 0?

Ver resolução

A soma dos positivos de v[0..n−1] é a soma dos positivos de v[0..n−2], mais v[n−1] se ele for positivo. É o mesmo formato da questão do maior elemento da P1: resolve o problema para os n − 1 primeiros e decide o que fazer com o último. Base: n = 0 (vetor vazio). A soma de nenhum número é 0, e é isso que faz a recursão funcionar: o primeiro elemento positivo é somado a 0. Para v = {3, −2, 5, 0, −7, 4}, o resultado é 3 + 5 + 4 = 12.

exercicio_recursividade_1.c

/* Exercício: soma dos elementos positivos de v[0..n-1], recursiva. */
#include <stdio.h>

/* Ideia: a soma dos positivos de v[0..n-1] é a soma dos positivos de
   v[0..n-2] mais v[n-1], se v[n-1] for positivo. Base: n == 0 -> soma 0
   (um vetor vazio não tem positivos). */
int soma_dos_positivos(int vetor[], int quantidade) {
    if (quantidade == 0) return 0;
    int soma_do_resto = soma_dos_positivos(vetor, quantidade - 1);
    int ultimo = vetor[quantidade - 1];
    return ultimo > 0 ? soma_do_resto + ultimo : soma_do_resto;
}

int main(void) {
    int vetor[] = {3, -2, 5, 0, -7, 4};
    printf("%d\n", soma_dos_positivos(vetor, 6));   /* 12 */
    printf("%d\n", soma_dos_positivos(vetor, 0));   /* 0 */
    return 0;
}

Exercício 2

Fonte: FEOFILOFF, P. Algoritmos em linguagem C. Rio de Janeiro: Elsevier, 2009. Disponível em https://www.ime.usp.br/~pf/algoritmos-livro/. Exercício 2.3.6 (adaptado).

Escreva o cálculo do n-ésimo número de Fibonacci (F(0) = 0, F(1) = 1, F(n) = F(n−1) + F(n−2)) de forma recursiva e de forma iterativa, e compare a eficiência das duas.

Ver resolução

A versão recursiva copia a definição, mas recalcula os mesmos valores muitas vezes: F(n) chama F(n−1) e F(n−2), F(n−1) chama de novo F(n−2), e assim por diante. O número de chamadas é 2F(n+1) − 1, que cresce exponencialmente (cerca de 1,6^n). A versão iterativa guarda só os dois últimos valores e faz n − 1 somas: O(n).

n     F(n)      chamadas da recursiva
5     5         15
10    55        177
20    6765      21 891
30    832040    2 692 537

É o exemplo da semana 1 (tempo_fibonacci_it_rec.c): a recursão é elegante, mas aqui é inviável.

exercicio_recursividade_2.c

/* Exercício: Fibonacci recursivo x iterativo — quantas chamadas e quantas somas. */
#include <stdio.h>

long chamadas = 0;

long fibonacci_recursivo(int posicao) {
    chamadas++;
    if (posicao <= 1) return posicao;
    return fibonacci_recursivo(posicao - 1) + fibonacci_recursivo(posicao - 2);
}

long fibonacci_iterativo(int posicao) {
    long anterior = 0, atual = 1;          /* F(0) e F(1) */
    if (posicao == 0) return 0;
    for (int passo = 2; passo <= posicao; passo++) {
        long proximo = anterior + atual;   /* uma soma por passo: n - 1 somas */
        anterior = atual;
        atual = proximo;
    }
    return atual;
}

int main(void) {
    int posicoes[] = {5, 10, 20, 30};
    for (int indice = 0; indice < 4; indice++) {
        int posicao = posicoes[indice];
        chamadas = 0;
        long resultado = fibonacci_recursivo(posicao);
        printf("F(%d) = %ld | recursivo: %ld chamadas | iterativo: %ld\n",
               posicao, resultado, chamadas, fibonacci_iterativo(posicao));
    }
    return 0;
}
