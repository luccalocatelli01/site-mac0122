# Site-da-Avalia-o-1-de-MAC0122
O EP pede um sistema em C que transforma o conteúdo da Avaliação 1 de MAC0122 num site: entram arquivos TXT, saem páginas HTML. O index.html aponta para 6 páginas indexadoras (Técnica, Algoritmo, Autores, Data, Conceitos e Problema), e cada uma lista as páginas que têm aquele rótulo. Uma parte obrigatória é o filtro que mostra código C colorido.
